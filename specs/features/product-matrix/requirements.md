# Product Matrix · Requirements

## 用户故事 · User Stories

- **US-01** 作为平台用户，我希望按业务应用层、AI 平台、数据平台和基础设施层浏览产品，以便快速找到需要的能力。
- **US-02** 作为平台用户，我希望点击产品类型后看到对应产品卡片，以便理解产品定位和可用入口。
- **US-03** 作为平台用户，我希望搜索产品并点击卡片进入工作台，以便直接开始使用。

## 验收标准 · Acceptance Criteria

- **AC-01** 根路径 `/` 展示产品矩阵首页，不再默认跳转到知识中心。
- **AC-02** 左侧产品类型至少包含全部产品、业务应用层、AI 平台、数据平台、基础设施层；Data Stack 作为数据平台下的一个产品展示。
- **AC-03** 点击产品类型后，右侧只展示该类型对应的产品卡片，并显示产品数量。
- **AC-04** 产品卡片展示名称、产品描述、能力摘要和进入产品的链接；Data Stack 的八个产品域能力摘要可直接进入对应工作台。
- **AC-05** 搜索框可以按产品名称、英文名、描述和能力名称筛选卡片；搜索“数据集成”等产品域名称时应展示 Data Stack；无结果时展示空状态。
- **AC-06** 首页全部内容使用本地 mock 配置，不请求真实 API。

## 非目标 · Out of Scope

- 不在首页实现产品内部的业务功能。
- 不新增独立测试中心、测试菜单或测试路由。
- 不接入真实产品目录服务、权限服务或推荐服务。
