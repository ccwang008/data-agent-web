# Solutions · Requirements

## 用户故事 · User Stories

- **US-01** 作为官网访客，我希望从顶部导航进入解决方案 Tab，以便按行业了解东方金信的能力。
- **US-02** 作为官网访客，我希望点击金融、工业、交通、能源、政务、教育或医疗，查看对应的方案说明和能力标签。

## 验收标准 · Acceptance Criteria

- **AC-01** `/solutions` 展示独立的行业解决方案页面，不显示通用数据平台工作台侧边栏和顶栏。
- **AC-02** 页面至少展示金融、工业、交通、能源、政务、教育、医疗七个行业入口，并使用本地图片素材。
- **AC-03** 点击行业入口后，仅切换当前行业的标题、描述、指标和标签，不请求真实 API。
- **AC-04** 顶部“产品矩阵”可返回 `/`，产品矩阵首页不再内嵌行业解决方案内容。
- **AC-05** 不新增测试中心、测试菜单或面向用户的测试页面。
