## 概述 · Overview

东方金信官网的独立解决方案 Tab 页面，展示金融、工业、交通、能源、政务、教育和医疗七类行业方案。页面使用本地图片和本地状态切换行业内容，不与产品矩阵首页混排，也不调用真实 API。
