## 概述 · Overview
为当前图实例提供四块 AI 能力入口, 不是泛泛"对话面板": **NL2Query**(自然语言转 Gremlin) · **GraphRAG**(检索增强问答) · **KG 自动构建**(文本→实体/关系) · **Graph ML**(嵌入 / 节点分类 / 链路预测目录占位)。所有能力走前端 mock, 不真正接 LLM。

## 用户故事 · User Stories
- **US-01** 作为业务用户, 我希望用自然语言提问, 系统生成 Gremlin / Cypher, 一键移交 04-analysis 执行
- **US-02** 作为业务用户, 我希望用自然语言提问, 系统答复带子图引用(GraphRAG)
- **US-03** 作为数据工程师, 我希望上传文本(PDF / Markdown / 纯文本), 系统自动抽取实体 / 关系, 走 03-import 后端写入图
- **US-04** 作为分析师, 我希望浏览 Graph ML 算法目录(嵌入 / 节点分类 / 链路预测), 选模型后跑训练 / 推理(走 async)

## 验收 · Acceptance Criteria (EARS)
- **AC-01 四入口** 页面应当呈四块卡片或 tab, 分别对应 NL2Query / GraphRAG / KG-Build / Graph ML, 与 hubble 通用对话面板形式区分
- **AC-02 NL2Query** 用户输入自然语言 → 系统生成 Gremlin(默认) / Cypher(可切换), 显示生成结果 + "移交 analysis" 按钮; 跳转后 04-analysis 顶部编辑器自动填入生成代码
- **AC-03 GraphRAG** 答复区应当含: 文本答复 + 引用子图片段(可点击放大到 mini 画布)
- **AC-04 KG-Build** 上传文本后, 系统应当显示"抽取中..." → 抽取完成显示实体 / 关系预览表 → "确认导入"按钮; 确认后任务移交 03-import + async-tasks
- **AC-05 Graph ML** 算法卡片网格, 三类: 嵌入(GCN / GAT / GraphSAGE) / 节点分类 / 链路预测; 与 06-computer OLAP 算法区分: 此处是在线 ML, 06 是离线 OLAP
- **AC-06 任务移交** AI 触发的任何耗时操作(KG 构建 / ML 训练) 均走 async-tasks (对应 `AC-G-HANDOFF`)
- **AC-07 对话记忆** NL2Query 与 GraphRAG 在同一会话内保留对话上下文(P2 可扩展为多 thread 并行, 灵感 Memgraph)

## 数据模型 · Data Model
```ts
interface NL2QueryRequest {
  graphId: string;
  question: string;
  targetLanguage: 'gremlin' | 'cypher';
}

interface NL2QueryResponse {
  query: string;                     // 生成的查询
  rationale?: string;                // 模型解释
  confidence: number;                // 0-1
}

interface GraphRAGRequest {
  graphId: string;
  question: string;
  contextDepth: number;              // 邻居跳数
}

interface GraphRAGResponse {
  answer: string;
  citations: Array<{ subgraphId: string; vertices: string[]; edges: string[] }>;
}

interface KGBuildRequest {
  graphId: string;
  text: string;                      // 纯文本; 上传文件由前端解析为文本
  domainHint?: string;
}

interface KGBuildPreview {
  extractedVertices: Array<{ label: string; name: string; properties: Record<string, unknown> }>;
  extractedEdges: Array<{ sourceName: string; targetName: string; label: string; properties: Record<string, unknown> }>;
}

interface GraphMLModel {
  key: string;                       // 'gcn' / 'gat' / 'graphsage' / 'node-classification' / 'link-prediction'
  family: 'embedding' | 'node-classification' | 'link-prediction';
  description: string;
  paramSchema: Array<{ key: string; label: string; type: 'number' | 'string' | 'boolean'; default?: unknown }>;
}

interface ChatThread {              // P2 多 thread 并行
  id: string;
  feature: 'nl2query' | 'graphrag';
  messages: Array<{ role: 'user' | 'assistant'; content: string; timestamp: string }>;
  modelName?: string;
}
```

## 交互与边界 · UX & Edges
- **空态**: 未选图实例 → 引导先去 01-graphs
- **错误**: LLM mock 失败时显示"AI 服务繁忙, 请稍后重试" + 重试按钮; 不破坏页面
- **超时**: 模拟生成 1-3s; 期间显示骨架 / 打字光标动效(80–120ms 节奏, 与视觉系统一致)
- **取消**: 生成过程可"取消", 不进入历史
- **大文本**: KG-Build 上传 ≥ 100KB 文本时, 前端预处理分块 + 进度提示
- **置信度展示**: NL2Query 答复底部显示 confidence bar(cobalt 主色), 低于 0.5 给警告
