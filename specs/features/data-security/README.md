## 概述 · Overview

数据安全功能定位为“面向 DCMM 第4级（量化管理级）的数据安全合规与证据管理工作台”，帮助数据安全负责人将安全能力从“有防护”升级为“能举证”。产品覆盖 GB/T 36073—2025 第 12 章的数据合规管理、数据安全防护和数据安全审计，并重点提供：

- 数据项级 AI 分类识别、复核审批和版本化分类分级报告。
- 中国大陆数据出境适用路径建议、检查清单、风险评估和重新评估。
- 过程、规范、合规、供应商四类安全审计及一键报告草稿。
- 安全事件台账、五阶段轻量 SOP、通知记录、演练与复盘。
- 独立的脱敏、加密和数据水印策略、模拟执行及证据记录。
- DCMM 第4级量化指标、证据缺口、整改和趋势管理。

产品提供就绪度、过程和证据支撑，不自动认定组织达到 DCMM 第4级，不替代外部评估、监管批准、法律意见或真实安全控制。

## 一级、二级和三级能力 · Information Architecture

一级菜单为“数据安全”，二级和三级菜单如下：

| 二级能力 | 三级菜单 |
|---|---|
| 安全总览 | 安全驾驶舱 |
| 数据合规管理 | 合规清单、合规审查、个人信息管理、重要数据管理、数据出境评估 |
| 数据分类分级 | 识别任务、复核审批、分类分级规则、分类分级报告 |
| 安全防护 | 防护策略、访问控制、脱敏管理、加密管理、数据水印、安全监控与风险 |
| 安全审计 | 审计计划、审计执行、审计证据、审计报告、问题整改 |
| 安全事件响应 | 事件台账、响应 SOP、通知与报告、演练与复盘 |

完整功能和当前路由见 [设计文档](./design.md)。现有实现覆盖正常、草稿、待复核、证据不足、执行中和完成等原型状态。

## 标准与规则基线 · Standards

- [GB/T 36073—2025《数据管理能力成熟度评估模型》](../../platform/references/GB_T_36073-2025_数据管理能力成熟度评估模型.pdf)：第 12 章数据安全及第4级量化管理要求。
- [GB/T 43697—2024《数据安全技术 数据分类分级规则》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F0C385EDC38CBF277AEC021F23126ADE)：分类分级与重要数据识别基础规则。
- [《促进和规范数据跨境流动规定》](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)：中国大陆数据出境路径与适用条件。
- [《数据出境安全评估申报指南（第三版）》](https://www.cac.gov.cn/2025-06/27/c_1752652339765002.htm)：安全评估申报材料和流程参考。
- [《个人信息出境认证办法》](https://www.cac.gov.cn/2025-10/17/c_1762449728720008.htm)：个人信息出境认证路径参考。

外部规则均以版本化合规规则包管理。产品中的检查结果是内部管理建议，不是法律结论。

## 当前实现 · Current Implementation

| 能力 | 当前实现 | 后续增强方向 |
|---|---|---|
| 分类分级 | 双轴分类、候选、复核、规则和报告 SQLite mock | 资产等级变化的跨模块影响传播 |

| 量化管理 | DCMM4 就绪矩阵、指标未知态、缺口和统一待办 | 历史趋势与管理层报告 |

## 原型边界 · Prototype Boundary

- 使用 `useSqliteState` 和 `data-agent.data-security.*` scope 持久化脱敏 mock 状态。
- 不接入真实数据源扫描、IAM、KMS、DLP、加密、脱敏、水印、安全监控、通知或监管申报系统。
- 不保存真实密码、token、密钥、私钥、完整连接串、原始敏感数据或真实监管材料。
- 模拟执行必须明确标记 mock，不得显示为生产控制已实施或监管流程已完成。
