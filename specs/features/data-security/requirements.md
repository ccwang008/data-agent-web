# Data Security · Requirements

## 验收标准 · Acceptance Criteria

- **AC-01** 分级分类页面展示对象范围、敏感等级、分类、负责人、审批和识别状态。
- **AC-02** 脱敏页面展示策略方法、适用范围、覆盖率和应用状态，并包含加密策略说明。
- **AC-03** 页面支持检索、创建、编辑、删除和确定性的 mock 执行动作。
- **AC-04** 可变状态使用 `data-agent.data-security.*` scope；不得保存真实密码、token、密钥和完整连接串。
- **AC-05** 页面结论是 DCMM 就绪度与证据结构演示，不代表真实合规或认证结论。
