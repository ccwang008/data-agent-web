## 概述

量化看板是一级跨域产品，用于按日监控 GB/T 36073—2025 九大能力域的 25 项核心 KPI，并以 33 个能力项映射、诊断指标、证据和改进事项解释结果。产品服务内部量化管理，不输出 DCMM 成熟度评分或认证结论。

数据标准域的三项核心 KPI 保持不变，并补充业务术语、主数据、参考数据、数据元标准、指标字典和跨能力版本迁移诊断。来源事实由目标 `data-standard` feature 权威维护；本 feature 只维护正式目标版本、观测、快照、趋势、报告和改进事项。

## 核心决策

- 一级菜单仅显示“量化看板”，无二级菜单。
- `/metrics` 展示综合看板；九大能力域通过九个独立路由 Tab 切换，形成“综合 + 九域”模式。
- 共享页头只保留公共操作和十个 Tab；时间筛选放在各看板内容区，并按看板独立保存与配置粒度。
- 九个能力域页面使用各自的业务视图，不复制同构页面模板。
- 25 项核心 KPI 是首期必达范围；DCMM 能力项映射和诊断指标只能补充，不能替换核心 KPI。
- 指标每天统一重算，保存日、周、月快照和季度量化管理报告。
- 人工填报、目标调整和改进事项直接生效并留痕，不建设审批或复核流。
