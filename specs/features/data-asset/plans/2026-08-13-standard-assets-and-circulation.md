# Data Asset · 数据标准资产化与资产流通计划（2026-08-13）

> 状态：部分废止。ADR-0020 已撤销“数据标准资产化”及其申请、授权、标准引用和下发范围；本计划只保留通用资产流通部分作为历史实施记录。

## 目标

新增一条不依赖数据产品包装的通用资产流通闭环，使申请、审批、对接和使用证据共享同一申请身份与资产版本快照。数据标准不进入该流程。

## 范围

1. 在 `DataAssetState` 中保留 `circulation` 分区和状态版本迁移，确保已有 `data-agent.data-asset` SQLite 状态补齐通用资产流程数据。
2. 保留 `/data-asset/circulation` 主从流程工作台，支持创建申请、负责人审批、条件性安全审批、对接推进及模拟使用留痕。
3. 数据表、数据集、文档和模型等非标准资产继续冻结申请时资产版本。
4. 数据标准 `AssetType`、专属元数据、fixture、标准引用交付方式和相关状态迁移不属于当前目标，应在后续代码实现中删除。

## 非目标

- 不把数据标准纳入资产目录或流通；独立 `data-standard` feature 是唯一目标事实源。
- 不连接真实审批引擎、IAM、API 网关、文件服务或消费系统。
- 不签发真实 token、账号或连接串，所有对接配置只保存脱敏 mock 摘要。
