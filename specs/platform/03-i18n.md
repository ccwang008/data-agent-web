# Platform · 国际化 · i18n

## 框架 · Stack
- `i18next` + `react-i18next` + `i18next-browser-languagedetector`
- 配置: `src/lib/i18n.ts`

## 支持语言 · Supported Locales
| Locale | 状态 | 角色 |
|---|---|---|
| `zh-CN` | ✅ 默认 | Default + primary |
| `en-US` | ✅ Fallback | Fallback |

## 命名空间策略 · Namespaces
| Namespace | 内容 | 文件 |
|---|---|---|
| `common` | 应用框架、导航、状态文案 | `src/locales/{locale}/common.json` |
| `<feature-key>` | 各 feature 内部文案 | `src/features/<key>/locales/{locale}.json` |

约定: feature 的 i18n namespace 名 = feature 目录名 = 路由路径。

## 使用 · Usage

```ts
// 默认 namespace = common
const { t } = useTranslation();
t("nav.data-source");

// 切换 feature namespace
const { t } = useTranslation("data-source");
t("title");
```

## 新增 feature 文案 · Adding a Feature Namespace
1. 创建 `src/features/<key>/locales/{zh-CN,en-US}.json`
2. 在 `src/lib/i18n.ts` 的 `resources` 与 `ns` 列表中追加 `<key>`
3. 页面用 `useTranslation("<key>")` 消费

## 新增语言 · Adding a Locale
1. `src/lib/i18n.ts` 的 `SUPPORTED_LOCALES` 添加常量
2. 创建 `src/locales/<locale>/common.json` 与各 feature `locales/<locale>.json`
3. `src/components/layout/TopBar.tsx` 的 `LOCALE_LABELS` 加显示文案
4. (可选)更新 `index.html` 的 `<html lang>` 默认值

## 文案约定 · Copy Conventions
- 短句优先, 句末**不加句号**(中文 / 英文都遵循)
- 占位符使用 `{{name}}` 双花括号
- zh-CN ↔ en-US 字数差异保持在 ±30% 内, 避免布局抖动
- 操作动词放句首 ("Search assets…" / "搜索资产…")

## 持久化 · Persistence
- 用户选择写入 `localStorage` 的 `data-agent.locale`
- 由 `src/stores/useLocaleStore.ts` 接管(rehydrate 时同步 `i18n.changeLanguage` + `<html lang>`)

## 反模式 · Anti-Patterns
- ❌ 在组件内拼接字符串("Hello, " + name) → 用 `{{name}}` 插值
- ❌ namespace 跨 feature 共享 (除 `common`)
- ❌ 在 fixture / mock 数据里塞中文/英文 (数据中性, 文案归 i18n)

## 关联文件 · Files
- `src/lib/i18n.ts`
- `src/stores/useLocaleStore.ts`
- `src/locales/*/common.json`
- `src/features/*/locales/*.json`
- `src/components/layout/TopBar.tsx` (LOCALE_LABELS)
