# ADR-0016 · 数据标准维护本体模型与语义层

## 状态 · Status

Superseded by ADR-0017

## 决策 · Decision

数据标准产品域是业务术语、本体模型、数据元标准、指标字典和语义层指标模型的唯一权威维护方。本体概念为业务术语提供统一语义身份，语义层指标模型为指标字典提供可执行计算表达；其他产品模块只能通过稳定对象 ID、版本和共享契约消费已发布定义，不能复制维护另一套可编辑事实。数据标准资产发布、外部申请授权和真实下发流程不属于本期范围。

## 后果 · Consequences

- 业务术语发布前必须绑定唯一有效本体概念；指标标准发布与语义层自动计算启用分离。
- 本体模型或语义层模型变更会触发标准影响分析、版本审批和受影响对象重新稽核。
- 数据治理、数据开发、数据资产和量化看板等模块使用稳定引用消费标准，不得直接 import 数据标准 feature 状态。
- 当前本地原型只保存 SQLite mock 定义、版本、引用和同步状态，不连接真实语义执行引擎或外部平台。

## 备选 · Alternatives Considered

- 本体模型和语义层由其他模块独立维护：可减少数据标准页面职责，但会造成术语、指标和执行语义多头管理。
- 数据标准域复制外部定义：接入较快，但会形成双重权威、版本漂移和无法闭环的影响分析。
