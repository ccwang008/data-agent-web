# ADR-0013 · 量化看板作为一级跨域产品

## 状态 · Status

Accepted

## 决策 · Decision

将“量化看板”建设为一级菜单和独立 feature，使用 `/metrics` 作为稳定入口，负责九大 DCMM 能力域的核心 KPI、指标观测值、目标版本、跨域证据引用和改进事项。一级菜单下不增加二级菜单或独立综合总览页；页面顶部固定展示全局摘要和九域状态，主体通过九个 Tab 切换能力域，每个 Tab 使用独立子路由，`/metrics` 默认进入数据战略。各能力域仍拥有自身业务事实和专项报告，现有 `/data-asset/reports` 继续作为数据资产域专项量化报告，不扩张为全组织 DCMM 看板；量化看板通过稳定标识引用各域事实，不直接依赖其他 feature 页面或复制来源记录。

## 后果 · Consequences

- 量化管理者可从一级入口查看组织全局态势，产品边界不会偏向任一能力域。
- 新 feature 需要独立维护需求、设计、任务、路由、菜单和 SQLite 状态范围。
- 跨域指标必须通过共享数据契约或稳定证据引用汇集，不能直接 import 其他 feature。

## 备选 · Alternatives Considered

- 放在“数据治理”下：菜单更紧凑，但会让数据治理这一能力域同时充当全部九域的产品容器。
- 复用 `/data-asset/reports`：改动较少，但会把组织级量化管理错误地归属于数据资产域，并混淆专项报告与全局看板。
